# WorldWise Travel App

A travel tracking web application built with React.

## Features

- Add and manage visited cities
- Interactive map integration
- Routing with React Router
- Responsive user interface
- State management using React hooks and context

## Technologies Used

- React.js
- React Router
- Context API
- CSS
- Vite

## Installation

```bash
npm install
npm run dev
```
